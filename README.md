# ระบบจองตู้ซักผ้าหอพัก

โปรแกรม Java จอเดียว สำหรับจองตู้ซักผ้าที่หอ
ระบุตัวตนด้วยเลขห้อง ไม่มีรหัสผ่าน ข้อมูลเก็บลงไฟล์ในเครื่อง

จองได้ 2 แบบ
- จองเลย ถ้าตู้เขียว จะเป็นส้ม 15 นาที แล้วค่อยกดเริ่มซัก (แดง 60 นาที) จบแล้วเหลืองให้เก็บผ้า
- จองชั่วโมงล่วงหน้า ตู้ยังเขียวอยู่ จนกว่านาฬิกาจะถึงชั่วโมงนั้น

รันโปรแกรมที่ GUI/DashboardUI.java (อย่ารัน App.java อันนั้นเป็นไฟล์เทส)
